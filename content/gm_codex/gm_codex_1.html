GM Codex

Introduction

Every SORC book, including this one, is available in hardback, softback, and PDF editions.

Access to the GM Codex itself is gated behind the SORC Assessment below, passing it issues a GM Code alongside the GM tag and profile update, and that code is what actually unlocks this book's content. A player who hasn't passed the Assessment doesn't receive a GM Code and cannot access the GM Codex.

GMs are required to take a SORC Assessment, which upon passing, grants their account GM references. Passing the GM Assessment also updates their account to a GM profile. For example, a player display name in tbis manner:
Player SirnamePC
Upon passing the GM assessment, GMs will gsve the following tag:
Game MasterGM
Sir names are optional and can be included as a space-separated second name. Each user is uniquely identified by a hidden id (shown here as data-uid) for online features, so display names may be the same, but user ids will always remain unique.

On top of directing campaigns, GMs can also play as characters.
