Bcrypt Migration Tool

Purpose: This tool runs the password reset migration to force existing email/password users to reset their passwords as they transition to bcrypt hashing.

Current Status

Migration Steps

Step 1: Check if migration has already been run
Step 2: Run the bcrypt migration

What This Does

  • ✓ Adds password_reset_required column to users table (if not exists)
  • ✓ Sets password_reset_required = 1 for all users with password_hash
  • ✓ Clears auth_key (logs out all email/password users)
  • ✓ Forces password reset on next login attempt
  • ✓ Leaves OAuth users (Google, Amazon, Apple) unaffected

After Migration

Users attempting to sign in with old credentials will see:

Password reset required.
Click here to reset your password
