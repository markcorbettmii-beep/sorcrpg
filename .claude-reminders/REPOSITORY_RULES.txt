⚠️ REPOSITORY RULES - NO DRAMA

MAIN BRANCH RULE:
- No merge commits allowed on main
- Must use rebase, not merge
- When deploying: git rebase (not git merge)

GIT WORKFLOW FOR DEPLOYMENT:
1. git checkout main
2. git rebase feature-branch  (NOT merge)
3. git pull --rebase origin main
4. git push origin main

DO NOT:
- Use git merge to main (violates repo rules)
- Try to do normal merge workflow
- Expect merge to work without errors

This avoids repository rule violations and drama.
Keep it simple. Just rebase and push.
