How Professions Work & Reference, A-M

How Professions Work

Skills are craftsmanship-based actions tied to a chosen Profession, creating items, gathering resources, and performing tasks that require knowledge, tools, recipes, and a suitable work area. Opening a Profession's current Proficiency Tier and raising an individual skill inside it are two separate purchases, same as Talents. Crafting resolves as d100 + Skill Score + Attribute Modifier vs. a Difficulty Score (DIFS) set by the GM. See Skills (TST) and Crafting Resolution, Basic Rules pg. 2.
