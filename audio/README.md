# Audio Files

Audio assets for sorcrpg.com

## Directory Structure

- **themes/** - Lobby theme background music (.ogg files)
- **effects/** - Sound effects like ready check alerts, notifications
- **ui/** - UI interaction sounds

## File Format

All audio should be in `.ogg` Ogg Vorbis format for web compatibility.

### Naming Convention

- Theme files: `{theme-name}.ogg`
- Effect files: `{effect-name}.ogg`
- UI sounds: `{ui-action}.ogg`
