Debugging Checklist

  • ✓ Check if RESEND_API_KEY environment variable is set
  • ✓ Verify the API key is valid (not expired)
  • ✓ Check if sending email domain is authorized (noreply@sorcrpg.com)
  • ✓ Verify test recipient email is correct
  • ✓ Check spam folder for emails
  • ✓ Review Resend.com dashboard for failed emails

Common Issues

  • Email not sent: Check that RESEND_API_KEY is configured in environment
  • Email in spam: Check email routing and sender reputation
  • Invalid domain: Domain must be authorized in Resend dashboard
  • API limit reached: Check if monthly email limit exceeded
